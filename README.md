# connectFour
Connect Four game made in Java using JavaFX.

A simple UI for both server and client use, making sure that players can play over the internet against each other.

Clone the repository into a directory of yours:
```
git clone https://github.com/jera1470/connectFour
```

Then in that directory, run:
```
mvn clean compile exec:java
```

There is a simple window that pops up that tells you to either go to the client or the admin server UI.
For your initial password, you should change it as soon as you can for your server's password to be different
from the given password, which is ```admin123``` (case sensitive).
Then you can activate the server and make multiple clients to register to that server.
Have fun with this small Connect Four multiplayer game!
